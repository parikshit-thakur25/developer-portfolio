As a **Computer Science & Engineering (CSE) student** preparing for software engineering and machine learning placement opportunities, I built this website to serve as my personal project showcase, hands-on learning lab, and online resume hub.

---

## 🎯 Purpose & Placement Journey

This project was built from the ground up to document my learning journey as a CSE student. Rather than relying on heavy templates or bloated frameworks, I built this using vanilla **HTML5**, **CSS3**, and **JavaScript** to master web fundamentals, DOM manipulation, and responsive UI design.

### Key Objectives:
- 🚀 **Placement & Internship Portfolio**: Presenting my real engineering projects (like **CardioVision AI**) to recruiters and tech teams.
- 🧪 **Hands-on Tech Lab**: Practicing full-stack web concepts, CSS glassmorphism, client-side file APIs (`FileReader`), and state persistence (`localStorage`).
- 🌐 **Custom Domain & Cloud Hosting**: Learning cloud deployment, CNAME custom domain routing ([parikshit07.tech](https://www.parikshit07.tech)), and Let's Encrypt HTTPS setup.

---

## 🔥 Features & Architecture

- **✍️ Cursive Handwriting Intro Splash Screen**: A handwriting preloader (`"hello ,"` ➔ `"parikshit"`) built with asynchronous typing logic and keyboard/click skip overrides.
- **💻 Cyber Terminal Widget (`parikshit@local:~$`)**: Interactive CLI simulator supporting commands like `whoami`, `status`, `skills`, `projects`, `contact`, and `clear`.
- **🫀 CardioVision AI Featured Project**: Direct integration showcasing my Clinical Heart Disease Risk Assessment Tool (built with Python, Scikit-Learn, and Flask).
- **🔐 Owner Admin Mode & PIN Security**: Protected admin panel (`1234` default, with dynamic `🔑 Change Password` support) allowing me to manage resume PDF uploads and deletions directly on the page.
- **📄 Client-Side PDF Resume Manager**: Uses HTML5 `FileReader` API and `localStorage` to upload, view, and store PDF resumes locally without external backend dependencies.
- **🎨 Deep Space & Crimson Red Glassmorphism**: Custom high-contrast color palette featuring deep charcoal red backgrounds, glowing ambient mesh orbs, and white action buttons.

## 🚀 Quick Start & Running Locally

### Option 1: Using the Automated Setup Script
```bash
# Clone the repository
git clone https://github.com/parikshit-thakur25/parikshit-portfolio.git
cd parikshit-portfolio

# Make the setup script executable and run it
chmod +x scripts/setup.sh
./scripts/setup.sh
```

### Option 2: Manual Python Local Server
```bash
# Launch a local HTTP development server on port 8000
python3 -m http.server 8000
```
Then open your browser and navigate to `http://localhost:8000`.
